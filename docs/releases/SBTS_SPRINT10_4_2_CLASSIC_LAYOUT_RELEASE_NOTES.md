SBTS Sprint 10.4.2 — Classic SBTS Layout Fidelity

Changes:
- Classic SBTS now uses a dedicated topbar + left sidebar shell matching the original SBTS patch style.
- Classic mode is no longer just color changes; it changes page frame, navigation density, header layout, card feel, button styling, and content width.
- Modern, SAP, and Custom themes remain unchanged.

How to test:
1. Settings -> General -> Theme Template -> Classic SBTS.
2. Save Settings.
3. User Profile -> Theme Mode -> Use System Settings theme.
4. Open Dashboard, Areas, Projects, Slip Blind, Reports.

Note:
This is a React/Vite implementation of the classic idea from the original SBTS patch. Page business logic remains the current professional React architecture.
