# SBTS Pilot User Guide

## What SBTS does
SBTS tracks blind isolation work digitally using:
- Areas
- Projects
- Blinds
- Phase updates
- Approvals
- Torque records
- QR tags
- Certificates
- Reports

## Basic user workflow

1. Login.
2. Open Dashboard.
3. Open Area.
4. Open Project.
5. Open Project Blinds.
6. Select a Blind.
7. Review current phase.
8. If assigned and authorized, update the phase.
9. Enter torque information when required.
10. Wait for final approvals.
11. Print or review certificate only when unlocked.

## Important user rules
- Do not update a phase unless you are assigned.
- Use correct badge/signature.
- Do not print a certificate if approval lock is active.
- Use QR only to review current blind information unless logged in.
- Report any incorrect role, phase, or approval issue to the pilot admin.

## Field use
For field work, the printed tag should be attached to the blind location. Scanning the QR should open the correct blind details page.
