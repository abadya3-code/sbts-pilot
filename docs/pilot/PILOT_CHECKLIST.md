# SBTS Pilot Checklist

## 1. Environment
- [ ] `pnpm install` completed.
- [ ] `.env` configured.
- [ ] `DATABASE_URL` configured.
- [ ] `pnpm db:push` completed.
- [ ] `pnpm db:verify` passed.
- [ ] `pnpm qa:security` passed.
- [ ] `pnpm qa:approval` passed.
- [ ] `pnpm qa:print` passed.
- [ ] `pnpm check` passed.
- [ ] `pnpm build` passed.

## 2. Admin configuration
- [ ] Company logo uploaded.
- [ ] Company name entered.
- [ ] Facility and department entered.
- [ ] Theme selected.
- [ ] Tag size verified.
- [ ] Certificate layout verified.
- [ ] Approval profiles reviewed.
- [ ] User roles verified.

## 3. Pilot data
- [ ] Pilot area created.
- [ ] Pilot project created.
- [ ] Minimum 5 blinds created.
- [ ] At least 1 Slip Blind created.
- [ ] At least 1 Drop Spool created.
- [ ] Phase assignment configured.
- [ ] QR tag printed.
- [ ] Certificate generated after approvals.

## 4. Workflow test
- [ ] Add blind.
- [ ] Update Broken / Preparation.
- [ ] Update Assembly.
- [ ] Update Tight & Torque.
- [ ] Enter torque data.
- [ ] Update Final Tight.
- [ ] Confirm approval requests are created.
- [ ] Approve all required approvals.
- [ ] Confirm certificate unlocks.
- [ ] Issue certificate.
- [ ] Print certificate.

## 5. Reports
- [ ] Dashboard summary reviewed.
- [ ] Reports Export Center reviewed.
- [ ] Blind register CSV exported.
- [ ] Print View saved as PDF.
- [ ] Tag Register saved as PDF.

## 6. Pilot sign-off
- [ ] Operations representative reviewed.
- [ ] Maintenance representative reviewed.
- [ ] Inspection / QA reviewed.
- [ ] Safety reviewed if applicable.
- [ ] Admin accepted known limitations.
