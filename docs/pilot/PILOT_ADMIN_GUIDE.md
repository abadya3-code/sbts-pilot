# SBTS Pilot Admin Guide

## Purpose
This guide helps the pilot administrator run SBTS in a controlled pilot without treating it as the official production source of truth yet.

## Admin responsibilities
- Configure Corporate Identity.
- Confirm users and roles.
- Create Areas.
- Create Projects.
- Assign phase task owners.
- Confirm approval profiles.
- Run print/PDF QA.
- Export pilot reports weekly.
- Maintain backup/export copies.

## Recommended admin setup sequence

1. Start the application.
2. Login as Admin.
3. Open Settings.
4. Configure:
   - Company Logo
   - Company Name
   - Facility
   - Department
   - Theme Template
   - Tag Settings
   - Certificate Settings
5. Open User Management.
6. Create or verify pilot users.
7. Create password credentials.
8. Open Areas.
9. Create pilot Area.
10. Open Projects.
11. Create pilot Project.
12. Open Project Dashboard.
13. Configure Phase Task Assignment.
14. Add sample blinds.
15. Test QR tag.
16. Test certificate lock.
17. Test final approvals.
18. Print sample tag and certificate.

## Pilot admin rule
Do not use SBTS as the official operational record until:
- database verification passes,
- authentication works,
- approval profiles are validated,
- print layouts are accepted,
- pilot sign-off is complete.
